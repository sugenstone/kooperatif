## M1-P9 kanıtları (execution `e2e-1793027626` + `e2e-1793034000`)

- **Format:** zarf v2 — AES-256-GCM chunked, HKDF-SHA256 per-arşiv anahtar
  (salt=`export_id`), 96-bit nonce (64b rastgele ‖ u32 sayaç), kanonik AAD,
  şifreli manifest + final chunk; plaintext asla diske düşmez.
- **Export:** tek `REPEATABLE READ READ ONLY` snapshot, 46 bölüm
  (42 coop + 4 global + synthetic users), akışlı SHA-256 + bağımsız `count(*)`
  paritesi, atomik `.partial`→publish.
- **Audit (O10-A):** `security_events`'te `coop_export_attempt/result`
  satırları; publish yalnız result-commit sonrası; post-publish hata
  `RECONCILE_REQUIRED`.
- **NULL-lane (O2-A):** pozitif zincir — `ura` NULL = üyelik + hedef-ait/kanıtlı
  rol + seed-dışı; `roles` NULL = kanıtlı `ura` referansı + seed-dışı;
  `security_events` NULL daima hariç; ambiguous → manifest exclusion / fail-closed.
  **Canlı kanıt:** üye NULL-ura dahil / üye-olmayan hariç / referanssız NULL rol
  hariç / platform-seed çoğaltma yok.
- **Restore:** yalnız disposable marker'lı hedef; preflight (bootstrap-identity,
  kullanıcı-çakışması, katalog-eşitliği, coop-yokluğu); tek-tx; UUID'ler verbatim;
  sentetik kullanıcı `disabled` + sentinel hash + `login_verifier NULL`
  (non-authenticable doğrulandı); `installation_state` dokunulmaz.
- **Negatifler (canlı):** audit-yazma-hatası→publish engeli; tekrar-restore reddi;
  `ON_ERROR_STOP`'suz `-c`'nin kısmi-commit'i → `runScript` ile düzeltildi,
  temiz rollback `post=0`.

## ADR-013 uyumluluğu

"Never-restored backup is not trusted" — gerçek restore kanıtı mevcut;
drill kapsamı export bütünlüğü + boş-şema restore doğrulamasını içerir;
operasyonel export audit'i arşiv payload'undan ayrık.
